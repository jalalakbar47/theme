# ZALMI SHOES

A real Astra child theme for WordPress, WooCommerce and Elementor Free. Installable package: `dist/zalmi-shoes-child.zip`.

This is an implemented starter storefront, not a verified production installation. PHP, WordPress, a database and the three free dependencies are absent from this workspace. Read the implementation report for unverified acceptance criteria.

- Theme: `wp-content/themes/zalmi-shoes-child`
- Elementor page designs: theme's `elementor-templates` directory (15 JSON files)
- Setup and editing guide: theme's `documentation/INSTALL.md`
- Inspection and testing: theme's `documentation/REPORT.md`
- Rebuild packages: `python3 tools/package.py`

No live payments, external WordPress accounts, deployment or customer data were accessed. Original sample shoe artwork is illustrative, not a photograph of a product for sale.
